# SCM
SCM stands for Sky Culture-Maker, creates the database of 
(1) Name of Sky Culture
(2) Names of Constellations, Stars and other Asterisms
(3) Stickfigure
(4) Convex Hull automatically computed
(5) The list of Stars associated to the Convex Hull
(6) Upload Artwork file with position (anchor) definition
(7) List of Stars, Planets and Deep Sky Object with their native names
